Stage A Supervisor
packages/lotus-supervisor		 Zero-Alloc Clone Landlock hidepid=2 Verifies Threads === 1 pre-fork and executes zero heap allocations between SYS_clone(CLONE_PIDFD | NEWUSER | NEWPID | NEWNET | NEWNS | NEWIPC) and execve. Mounts private /proc (MS_NOSUID|NODEV|NOEXEC, hidepid=2), zeroes all capabilities, applies Landlock (RO libs/fonts, RW 0o700 /tmp/lotus-sandbox-*, BindTcp = 0), and sanitizes FDs via close_range + [bool; 64] stack bitmap.
Stage B Syscall Lockdown
lotus-engine/src/stage_b.rs		 SECCOMP_FILTER_FLAG_TSYNC SIGSYS Applied at Statement 1 of lotus-engine::main() prior to ServoBuilder::build() (77/77 threads locked in Seccomp: 2). Kills SYS_fchmod, SYS_fchmodat, SYS_ptrace, SYS_mount, SYS_execve, SYS_unshare, and SYS_setns with SIGSYS. Host inspects /proc/<pid>/status and mountinfo at STAGE_B_LOCKED before unlocking via PROCEED_TO_INIT.
Split-Plane SHM Seqlock
shm.rs & gl/shm_consumer.rs		 pixel_rw / pixel_ro ack_rw / ack_ro Allocates two independent sealed memfd planes per pane. Read-only FDs are hardened by reopening /proc/self/fd/<rw_fd> with O_RDONLY, setting fchmod(0o400), and sealing (F_SEAL_SHRINK|GROW|SEAL) while Stage B blocks SYS_fchmod. Lock-free Seqlock (FREE → WRITING → READY) streams tear-free BGRA frames to OpenGL.
Anti-SSRF Network Broker
network_broker.js		 DNS Socket Pinning HostCookieStore lotus-net-proxy inside CLONE_NEWNET forwards over broker_socket. Host blocks loopback, RFC 1918, link-local, CGNAT, ULA, 6to4, Teredo, and NAT64; resolves all DNS records (all: true) and pins verified IPs at the socket lookup callback to defeat DNS rebinding. Enforces double-keyed (surfaceId, topLevelSite) cookies and 64 MiB quotas.
Track 2 IPC & Realm Guard
ipc_security.rs & host_ipc_policy.js		 Top-Realm Guard Pre/Post-Await Injected via Servo UserContentManager and tunneled over broker_socket. Blocks cross/same-origin <iframe> callers via verifyTopRealm (TopObject/Function/Array/Error checks). Enforces 256-bit constant-time bootstrap auth, single-use tickets protected by auth_failure_limiter, pre/post-await activeDocumentId checks, and two-phase output projection.
Sandboxed Panes API
win.createPane() & LayoutBuilder		 sandbox: true allowedChannels Spawn process-isolated untrusted or external web views with win.createPane(id, { sandbox: true, allowedChannels: ['vault'] }) or layout.fill('view', { sandbox: true }). Automatically runs inside PID_secure_engine, enforces zero host filesystem access via Landlock, proxies egress via NetworkBroker anti-SSRF, and grants capability-scoped Track 2 IPC.
